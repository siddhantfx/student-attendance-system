# Student Attendance Management System

## Problem Statement
Keping attendance on physical paper registers is slow and easily leads to lost or damaged records. It is also difficult and time-consuming for teachers to manually calculate total attendance percentages and find out which students fall below the 75% of attendance requirement.

## Scope of the Project
This project provides a simple command-line Python program to store student information and mark daily attendance. It saves all records to local text files and automatically calculates attendance percentages to show who has attendance below 75%.

## Target Users
- Teachers and professors
- Lab instructors
- Academic administrators

## High-Level Features
- Add and save student details (roll number, name, class)
- Mark daily attendance as Present or Absent of student
- Display a list of all registered students
- Search and view attendance history for an individual student by giving its roll number.
- Generate a summary report calculating percentages and highlighting defaulters below 75%
